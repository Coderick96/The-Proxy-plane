## Transport repairs

Three generated images can exceed Vercel's buffered-response limit. Successful AI responses and recovered results now stream private JSON, preserving the API's JSON response shape and durable result contract. Serverless re-sketch references are bounded before spending credits; the browser prepares oversized references as JPEG with preserved aspect ratio and a maximum side of 1536 pixels. Transparent source areas become white for reference upload. Selected original images remain unchanged.

The browser client retains operation IDs when preparation fails or a JSON stream is interrupted. A changed account during image preparation aborts before fetch. A truncated HTTP-200 response is rejected rather than interpreted as successful generation.
